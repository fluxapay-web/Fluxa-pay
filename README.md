# 💸 Fluxa Pay

A modern smart financial web/app for sending, receiving, and managing money across the USA, Europe, and Qatar.

---

## 🌍 Overview

Fluxa Pay is a fast, secure, and user-friendly digital payment platform designed for global transactions. It enables individuals and businesses to send and receive money seamlessly across regions with a clean and modern interface.

---

## 🚀 Features

- ⚡ Instant money transfers
- 🔐 Secure Firebase authentication
- 🌍 Multi-region support (USA, Europe, Qatar)
- 📱 Responsive web & mobile-friendly UI
- 💳 Smart financial dashboard
- 👤 Personal & business use support

---

## 🧠 Tech Stack

- Frontend: (React / Next.js / your choice)
- Backend: Firebase
- Database: Firestore
- Authentication: Firebase Auth
- Hosting: Firebase Hosting

---

## 🔐 Security

Fluxa Pay follows security-first principles:
- Environment variables are never exposed
- Firebase security rules enforced
- Sensitive keys excluded via `.gitignore`
